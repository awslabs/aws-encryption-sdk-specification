# AES Keyring

## Overview

A keyring which uses a caller-provided AES key to encrypt and decrypt data keys locally, without calling an external key management service.

## Definitions

### Conventions used in this document

The key words "MUST", "MUST NOT", "REQUIRED", "SHALL", "SHALL NOT", "SHOULD", "SHOULD NOT", "RECOMMENDED", "MAY", and "OPTIONAL" in this document are to be interpreted as described in [RFC 2119](https://tools.ietf.org/html/rfc2119).

## Interface

The AesKeyring MUST implement the [Keyring interface](https://github.com/awslabs/aws-encryption-sdk-specification/blob/master/s3-encryption/materials/keyrings.md#interface) and include the behavior described in the [S3 Keyring](https://github.com/awslabs/aws-encryption-sdk-specification/blob/master/s3-encryption/materials/s3-keyring.md).

## Initialization

On initialization, the caller MUST provide an AES wrapping key.

If the caller provides a null wrapping key, the AesKeyring MUST throw an exception.

If the implementing language provides an AES-specific key type or algorithm identifier, the AesKeyring MUST reject a wrapping key that does not use that type or identifier.

The wrapping key MUST contain 128, 192, or 256 bits of key material. If the wrapping key has any other length, the AesKeyring MUST throw an exception.

On initialization, the caller MAY provide a Materials Description, a map of string keys to string values which describes the wrapping key.

The AesKeyring MAY support additional decryption key material, represented as a map from Materials Description to AES wrapping key.

On initialization, the caller MAY provide the option to enable legacy wrapping algorithms. If the caller does not provide the option to enable legacy wrapping algorithms, legacy wrapping algorithms MUST be disabled.

## Supported Wrapping Algorithms

The wrapping algorithm is identified by the Key Provider Info of the [encrypted data key](../structures.md#encrypted-data-key).

| Key Provider Info | Wrapping algorithm | Legacy | Encrypt | Decrypt                                        |
| ----------------- | ------------------ | ------ | ------- | ---------------------------------------------- |
| "AES/GCM"         | AES/GCM            | no     | yes     | yes                                            |
| "AESWrap"         | AESWrap            | yes    | no      | only if legacy wrapping algorithms are enabled |
| "AES"             | AES                | yes    | no      | only if legacy wrapping algorithms are enabled |

The AesKeyring MUST encrypt with AES/GCM. The AesKeyring MUST NOT encrypt with AESWrap. The AesKeyring MUST NOT encrypt with AES. The AesKeyring MUST support decryption using AES/GCM. The AesKeyring MUST support decryption using AESWrap. The AesKeyring MUST support decryption using AES.

### OnEncrypt

The AesKeyring MUST implement the OnEncrypt operation. If a non-empty Materials Description was provided on initialization, OnEncrypt MUST set it on the [encryption materials](../structures.md#encryption-materials). The AesKeyring MUST NOT use the [encryption context](../structures.md#encryption-context) to encrypt the data key. If the input encryption materials do not contain a plaintext data key, OnEncrypt MUST generate one using a cryptographically secure random number generator. The generated plaintext data key MUST have the data-key length specified by the algorithm suite in the encryption materials.

OnEncrypt MUST encrypt the plaintext data key using AES-GCM with parameters constructed as follows:

- The cipher key MUST be the configured wrapping key.
- The IV MUST be a fresh 12-byte value generated by a cryptographically secure random number generator for each data key encryption.
- The authentication tag length MUST be 128 bits.
- The plaintext MUST be the plaintext data key in the encryption materials.
- The AAD MUST be the UTF-8 encoding of the content-cipher identifier defined by the algorithm suite in the encryption materials.

If the input encryption materials contain a non-empty encryption context, OnEncrypt SHOULD throw an exception. If throwing an exception would be a breaking change for an existing implementation, OnEncrypt MUST NOT throw solely because the encryption context is non-empty. If throwing an exception would be a breaking change for an existing implementation, OnEncrypt MUST emit a warning that the encryption context provides no security benefit when using the AesKeyring.

If AES-GCM encryption does not succeed, OnEncrypt MUST throw an exception.

- The Key Provider ID MUST be "S3Keyring".
- The Key Provider Info MUST be "AES/GCM".
- The Ciphertext MUST be a single byte sequence formed by concatenating, in order, the bytes representing the IV, the AES-GCM ciphertext, and the authentication tag.

OnEncrypt MUST return the output EncryptionMaterials containing the plaintext data key and encrypted data key.

### OnDecrypt

The AesKeyring MUST implement the OnDecrypt operation. The AesKeyring MUST choose the wrapping algorithm from the Key Provider Info of the Encrypted Data Key, using the table in [Supported Wrapping Algorithms](#supported-wrapping-algorithms). If the Key Provider Info is not "AES/GCM", "AESWrap", or "AES", OnDecrypt MUST throw an exception. If decryption using AESWrap is attempted while legacy wrapping algorithms are not enabled, OnDecrypt MUST throw an exception. If decryption using AES is attempted while legacy wrapping algorithms are not enabled, OnDecrypt MUST throw an exception.

If decryption fails, OnDecrypt MUST throw an exception and MUST NOT set the plaintext data key. If decryption succeeds, OnDecrypt MUST set the resulting plaintext data key on the output DecryptionMaterials and return the output DecryptionMaterials.

#### Decryption Key Selection

The wrapping key provided during initialization is the primary wrapping key. If additional decryption key material is configured and the Materials Description in the decryption materials exactly matches an entry, OnDecrypt MUST select the AES key associated with that entry. If no entry matches, or no additional decryption key material is configured, OnDecrypt MUST select the primary wrapping key. Two Materials Descriptions MUST be considered a match if and only if they contain exactly the same keys and values, regardless of entry order. Each additional decryption key MUST satisfy the wrapping-key requirements defined in [Initialization](#initialization).

#### AES/GCM

When AES/GCM is selected, OnDecrypt MUST decrypt the [encrypted data key ciphertext](../structures.md#ciphertext) using AES-GCM with parameters constructed as follows:

- The cipher key MUST be the selected decryption key.
- The IV MUST be the first 12 bytes of the encrypted data key ciphertext.
- The ciphertext and authentication tag MUST be the remaining bytes of the encrypted data key ciphertext.
- The authentication tag length MUST be 128 bits.
- The AAD MUST be the UTF-8 encoding of the content-cipher identifier defined by the algorithm suite in the [decryption materials](../structures.md#decryption-materials).

OnDecrypt MUST verify the AES-GCM authentication tag before setting the plaintext data key.

#### AESWrap

When AESWrap is selected, OnDecrypt MUST un wrap the [encrypted data key ciphertext](../structures.md#ciphertext) using the AES Key Wrap algorithm defined in [RFC 3394](https://www.rfc-editor.org/rfc/rfc3394) with the selected decryption key.

#### AES

When AES is selected, OnDecrypt MUST decrypt the [encrypted data key ciphertext](../structures.md#ciphertext) using AES in ECB mode with the selected decryption key and remove PKCS #7 padding with a 16-byte block size.
